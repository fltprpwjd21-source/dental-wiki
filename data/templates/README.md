# 문서 정리 틀 (작성 안내)

기존 파워포인트·엑셀·종이 문서를 위키에 넣기 전에, 이 폴더의 틀을 복사해
마크다운 파일로 정리합니다.

> **이 폴더의 파일은 위키에 등록되지 않습니다.** 등록되는 것은
> `data/seed-docs/` 안의 `.md` 파일뿐입니다. 여기서 틀을 복사해 그쪽에 저장하세요.

## 작업 순서

1. 아래 표에서 문서 종류에 맞는 틀을 고릅니다.
2. 그 파일을 `data/seed-docs/` 로 복사하고 이름을 바꿉니다.
3. 내용을 채웁니다.
4. 전부 채운 뒤 등록합니다.

```bash
cp data/templates/1-인수인계.md "data/seed-docs/보철과-임플란트2차수술.md"
# 내용을 채운 다음
npm run seed:docs
```

| 원본 문서 | 쓸 틀 | `category` 값 |
|---|---|---|
| 진료과별 인수인계 (주로 파워포인트) | `1-인수인계.md` | `handover` |
| 보험 수가·비보험 항목 (주로 엑셀) | `2-수가.md` | `insurance` |
| 병원 내규·운영회칙 (종이·공유 파일) | `3-내규.md` | `policy` |

## 반드시 지킬 것

### 1. 맨 위 3줄 형식은 바꾸지 않습니다

```markdown
---
category: handover
title: 보철과 인수인계 - 임플란트 2차 수술 준비
---
```

- `---` 로 시작하고 `---` 로 닫습니다. 이 형식이 깨지면 등록이 실패합니다.
- `category` 는 `handover` / `insurance` / `policy` 중 **하나만** 씁니다. 오타가 나면 실패합니다.
- `title` 은 화면 목록과 답변의 "근거 문서"에 그대로 표시됩니다.
  나중에 앱에서 수정할 수 있으니 부담 갖지 않아도 됩니다.

### 2. 환자 개인정보는 절대 넣지 않습니다

이름, 차트번호, 생년월일, 연락처, 촬영 영상, 진료 기록 — 어떤 형태로도 넣지 않습니다.
예시가 필요하면 "A 환자", "성인 남성" 처럼 특정할 수 없게 씁니다.

### 3. 문서 하나에 주제 하나

"보철과 인수인계 전체"를 한 파일에 몰아넣지 말고, 주제별로 나눕니다.
검색은 문서 단위로 이뤄지므로, 한 문서에 여러 주제가 섞이면 엉뚱한 문서가 근거로 잡힙니다.

- 나쁨: `보철과.md` (임플란트 + 크라운 + 틀니 + 장비 전부)
- 좋음: `보철과-임플란트2차수술.md`, `보철과-크라운본뜨기.md`

## 검색이 잘 되게 쓰는 요령

이 위키는 질문의 **의미**로 문서를 찾습니다. 그래서 쓰는 방식이 검색 품질을 크게 좌우합니다.

### 요령 1 — 직원이 실제로 쓸 말을 문서에 넣습니다

가장 효과가 큽니다. 공식 용어만 쓰면 평소 말로 물었을 때 안 찾아집니다.

- 직원이 묻는 말: "임플란트 2차 수술 때 뭐 준비해요?"
- 문서에 "지대주 연결 술식 준비 물품" 만 있으면 → 잘 안 걸립니다
- 문서에 "임플란트 2차 수술 준비물" 도 함께 있으면 → 잘 걸립니다

공식 용어와 평소 쓰는 말을 **둘 다** 적어두세요.
`지대주(어버트먼트)` 처럼 괄호로 병기하면 양쪽 다 검색됩니다.

### 요령 2 — 각 절이 혼자서도 이해되게 씁니다

나중에 긴 문서는 `##` 절 단위로 잘라서 검색합니다. 잘린 조각만 AI에게 전달되므로,
"위에서 말한 그것" 같은 표현은 조각만 보면 무슨 말인지 알 수 없습니다.

- 나쁨: `## 주의사항` → "이때 반드시 확인한다"
- 좋음: `## 임플란트 2차 수술 주의사항` → "임플란트 2차 수술 전에 반드시 확인한다"

절 제목에 주제를 한 번 더 넣어주면 좋습니다.

### 요령 3 — 표보다 목록이 안전합니다

간단한 항목은 `- 항목: 값` 형태의 목록이 검색에 더 잘 걸립니다.
표는 여러 항목이 한 줄에 붙어 의미가 흐려지기 쉽습니다.
항목이 많아 표가 꼭 필요하면 써도 되지만, 그럴 땐 문서를 더 잘게 나누는 편이 낫습니다.

### 요령 4 — 모르는 건 비워둡니다

확실하지 않은 내용을 추측해서 채우면, AI가 그걸 근거로 자신 있게 잘못 답합니다.
비워두면 "위키에 등록된 정보가 없습니다"라고 답하니 훨씬 안전합니다.
